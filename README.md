# Excel & Data Fundamentals — Sales Performance Dashboard

## 📌 Project Overview
This repository contains the **Week 1 Assignment** focused on Excel basics, data cleaning, descriptive statistics, and building interactive Pivot Table Dashboards using the **Global Superstore** dataset.

---

## 🛠️ Key Deliverables
1. **Descriptive Statistics**: Computed Mean, Median, Mode, Variance, and Standard Deviation for Sales and Profit metrics.
2. **Data Cleaning**: Prepared order dates, verified missing values, and created calculated helper columns.
3. **Pivot Table Dashboard**:
   * **Total Revenue**: $12,642,501.91
   * **Sales by Category**: Technology leads with $4.74M (37.5%).
   * **Yearly Trends**: Consistent annual growth from $2.26M (2012) to $4.30M (2015).
   * **Market Revenue**: Asia Pacific ($4.04M) and Europe ($3.29M) are top revenue drivers.
